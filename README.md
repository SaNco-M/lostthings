# LostThings

**LostThings** — веб-приложение для поиска потерянных и найденных вещей и животных.

Пользователи могут публиковать объявления о пропаже или находке, просматривать объявления и связываться с их авторами. В дальнейшем планируется добавить поиск совпадений, уведомления и поддержку приютов для животных.

## Технологии

- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Migrations:** Alembic
- **Frontend:** HTML, CSS, JavaScript

## Цель проекта

Создать удобную платформу, которая помогает людям находить потерянные вещи и животных и возвращать их владельцам.
